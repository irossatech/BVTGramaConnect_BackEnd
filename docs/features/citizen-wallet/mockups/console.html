Notes for review

  • The page shows to holders of the new wallet permissions; today only the Super Admin.
  • No screen shows a full email or mobile number; CSV exports carry the same masked values.
  • "Adjust points" opens a dialog with whole points (plus or minus) and a required reason; a balance cannot go below zero.
  • Block, Unblock and Delete ask for a reason, like the existing user actions. A blocked account shows Unblock instead of Block; a deleted one ("Deleted citizen") has no actions. The buttons follow each row's allowed_actions.
  • Wallet entries tab (frame 4d): every entry in pages, with the export's filters; decided by the Admin on 2026-11-25 (option a), served by GET /admin/wallet/entries/.
  • CSV exports: referrals and wallet entries only (J8), with the same masked values; accounts are not exported.
  • Settings errors show under the field, for example "These are not active mandals: 99" or "The active days cannot be more than the days points are held (7)".
  • The existing Notification texts page lists three new texts with the recipient "The citizen's wallet account": a friend joined, points confirmed, points not confirmed.
  • The page works while the wallet is switched off, so the Super Admin can still help, export and delete.
