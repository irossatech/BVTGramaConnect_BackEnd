Notes for review

  • The sender address is an example; the client chooses it (C7, BVTGC-143).
  • No links in the emails: links in code emails are a common phishing pattern, and the app does not need them.
  • The code is in the subject on purpose, so a villager sees it in the phone's notification without opening the email.
  • These are the texts the server sends today (apps/citizens/templates/citizens/email/, BVTGC-122); a change agreed here goes there too. Every email goes in the citizen's language.
  • The "email changed" notice also goes when the Super Admin sets a new email after a call-back (D16).
